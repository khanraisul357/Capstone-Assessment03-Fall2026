Food Left at Closing Time
Spring Boot + React (Vite)

A food rescue system designed to reduce food waste by connecting restaurants with people who need surplus food.

1. Project Overview

This project consists of two main parts:

Backend: Java Spring Boot
Frontend: React with Vite
2. Backend Setup (Spring Tool Suite)
Extract the food-rescue-system.zip file.
Open Spring Tool Suite (STS).
Navigate to File → Import → Maven → Existing Maven Projects.
Select the food-rescue-system/backend folder.
Click Finish.
Find FoodRescueApplication.java.
Right-click and select Run As → Spring Boot App.

Backend URL: http://localhost:8080

3. Frontend Setup (React + Vite)
Open the project folder in VS Code.
Open the terminal.
Navigate to the frontend directory:
bash
cd frontend

Install dependencies:
bash
npm install

Start the development server:
bash
npm run dev


Frontend URL: http://localhost:5173
