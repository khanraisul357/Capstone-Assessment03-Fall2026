# Food Left at Closing Time — Spring Boot + React

## 1. Open & Run Backend in Spring Tool Suite (STS)
1. Extract `food-rescue-system.zip`.
2. In STS: **File -> Import -> Maven -> Existing Maven Projects**.
3. Browse to `food-rescue-system/backend` and click **Finish**.
4. Right-click `FoodRescueApplication.java` -> **Run As -> Spring Boot App** (runs on `http://localhost:8080`).

## 2. Run Frontend (React + Vite)
```bash
cd food-rescue-system/frontend
npm install
npm run dev
```
Open `http://localhost:5173`.
